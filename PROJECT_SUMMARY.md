# PROJECT_SUMMARY.md

## Problem Solved

Finance teams spend countless hours manually processing invoices, categorising vendors, prioritising payments, and drafting reminder emails. Errors and delays hurt cash‑flow visibility and increase the risk of late fees.

## Approach

We built a **single‑screen web app** that ties together:
- **Google Gemini Vision** for OCR extraction of invoice fields.
- **Gemini LLM** for vendor classification and priority scoring.
- **FastAPI** backend that orchestrates the AI calls, stores data in SQLite, and exposes a clean REST API.
- **React** frontend that presents a polished dashboard with glass‑morphism cards, status badges, and responsive layout.

If the Gemini API key is missing or the appropriate multimodal model is unavailable, the system automatically falls back to a **deterministic mock** (based on the file‑path hash) that still produces unique outputs per invoice.

- **Frontend**: Vite‑powered React, vanilla CSS with custom design tokens (primary color `#2563EB`).
- **Backend**: FastAPI routers for invoices and receivables, Pydantic schemas, utility module for Gemini integration.
- **AI Components**:
  - `extract_invoice` – real OCR via `google.genai` or deterministic mock.
  - `classify_vendor` – LLM prompt returning category and reasoning.
  - `compute_priority` – rule‑based engine with AI‑enhanced weighting.
  - `generate_email` – LLM drafting of polite reminder emails.

## Business Value

- **Speed**: Invoice data appears instantly after upload, eliminating manual entry.
- **Accuracy**: AI‑driven extraction reduces human error.
- **Prioritisation**: Scores help finance teams focus on high‑impact payments.
- **Automation**: AI‑generated email drafts cut down on repetitive communication.
- **Scalability**: Architecture can be extended with ERP integrations and cash‑flow forecasting.
